# Roadmap (proposals, not implemented)

- v0.2: reproducible benchmark harness with timing, confidence intervals, and BM25 ablations
- v0.3: opt-in embeddings adapters, typed and normalized entities, better sentence segmentation
- v0.4: graph ranking using personalized PageRank and evidence-aware subgraph selection
- v0.5: optional local LLM synthesis with citation entailment checks and contradiction detection
- v1.0: incremental indexing, persistence integrity, dataset-scale profiling, external audit

Feature priorities will respond to contributions and evidence, not hype. GraphRack does not presently achieve these capabilities.
