# Contributing to GraphRack

Thank you for helping. Before filing an issue, check existing issues. For code changes, create a focused branch, document trade-offs, add tests, run `python -m pytest -q` and `ruff check src tests`, and open a descriptive pull request. Never commit secrets, private source corpora, generated indexes or personal data. Discussions on evaluation, multilingual segmentation, and graph extraction are particularly welcome. Please be respectful and follow the code of conduct.
